# Локальний архів товарів MTech

Пілот: 10 товарів із публічного українського каталогу `mtech-cnc.com.ua`. Архів зберігається в `data/mtech-product-archive/`; каталог `data/` вже виключено з Git. Публікація сайту та імпорт у Vector ERP не виконуються.

## Запуск

З кореня проєкту в PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r scripts/mtech-extraction-requirements.txt
.\.venv\Scripts\python.exe -X utf8 scripts/extract_mtech_sample.py
```

Один товар: додайте `--product-id 2337803974`. Параметр можна повторювати. Без параметра завантажуються ті самі 10 пілотних товарів. Для нового ID поза пілотом категорія потребує окремого зіставлення; код не вгадує її автоматично.

Звичайний повторний запуск оновлює дані сторінок, але повторно використовує справні локальні зображення за ID джерела (або URL для зображень іншого домену). Для перевірки зміни вмісту фото за незмінним ID додайте `--refresh-images`: застосовуються HTTP-валідатори, якщо сервер їх підтримує; інакше файл завантажується для порівняння SHA-256. Старі версії зберігаються. Видалення товарів із джерела цим обмеженим пілотом не синхронізується.

## Структура

- `originals/<product-id>/`: незмінені отримані зображення, назви містять ключ джерела та хеш. Однакові файли можуть спільно використовуватися кількома товарами.
- `products/<product-id>/current.json`: поточні вихідні дані.
- `products/<product-id>/revisions/<hash>/`: версії даних, HTML сторінки, опис HTML і текст.
- `manifest.json`: повні дані, зокрема фото, характеристики, таблиці опису, шляхи та хеші.
- `manifest.csv`: коротка таблиця товарів; точні вихідні значення збережено в JSON.
- `catalogue-products.json`: дані для майбутнього підключення каталогу; локальні шляхи зображень відносні до кореня архіву.
- `asset-index.json`: локальний кеш зображень і HTTP-валідаторів.
- `review/index.html`: автономний візуальний огляд галерей, описів і характеристик.
- `edited/<product-id>/`: резерв для покращених фото. Екстрактор сюди не записує.
- `editorial/`: резерв для відредагованих текстів. Екстрактор сюди не записує.
- `reports/`: звіти запусків, помилки й попередження про роздільну здатність.

Для майбутнього редагування потрібно пов'язувати результат із `source_product_id`, `source_image_id` або `source_url` та `sha256` конкретного оригіналу. У пілоті редагування й автоматичне застосування редакційних змін ще не реалізовані.

Ціни зберігаються десятковими рядками без втрати точності. Коди не транслітеруються. Наявність і показана кількість — датований знімок сайту, а не перевірені залишки ERP. Тексти зберігаються мовою джерела навіть за наявності змішаних українських і російських формулювань. Таблиці всередині опису зберігаються окремо від стандартних характеристик; HTML також зберігає початкову структуру.

Зображення галереї та опису зберігаються окремими зв'язками. Прев'ю відео не включаються до фото; зберігаються їхні вихідні посилання. Посилання на документи в описі записуються, самі документи пілот не завантажує. Сирий HTML є матеріалом джерела: перед публікацією його потрібно очистити. Локальний огляд показує екранований текст.

## Перевірка

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/test_mtech_archive.py
.\.venv\Scripts\python.exe -m http.server 4186 --bind 127.0.0.1 --directory data/mtech-product-archive
```

Огляд: `http://127.0.0.1:4186/review/index.html`. Можна також відкрити `review/index.html` без сервера. Перші перевірки охоплюють повторне використання фото без мережевого запиту, збереження старої версії при зміні джерела, недоторканність покращеного файлу та незмінність метаданих при повторній перевірці того самого зображення.
